# Ardoise web editor (wordcraft fork)

Web build of the Ardoise editor, based on WordCraft by Learning Machines LLC (Apache-2.0 OR MIT).
Branch `ardoise` starts from upstream tag v0.4.0 (https://github.com/storytold/wordcraft).

Changes in this fork: postMessage bridge for same-origin iframe embedding (apps/wordcraft-web/src/web.rs),
Ardoise branding in the UI (the upstream name, wordmark and logos are not used), single web-only CI
workflow (.github/workflows/web.yml).
